# Compact list revision

The current human surface is a continuous list rather than a card grid or kanban board. Rows show title and status. Updates and next steps appear only when expanded; evidence and history require a second disclosure. Canonical states, cancellation uncertainty, synthetic evidence, and the separate agent payload are preserved.

Verified in Chromium at 1440 × 960 and 390 × 844: six rows, closed defaults, keyboard Enter disclosure, no horizontal overflow, search empty state, and reset. Desktop and mobile screenshots were rendered. This is a static prototype; backend and live A2UI gates remain NOT RUN. Earlier kanban acceptance evidence is historical and does not validate this revision.
